# Sohan Rajpurohit

**Telegram bot developer · Founder of BotNex**

I build Telegram bots that run channels, stores and communities on their own — so owners can focus on content, not setup.

## What I build

- **Movie & media bots** — BotNex Movies Hub, auto-filter bots that answer searches with the right file in seconds
- **File Store bots** — send a bot token, get your own working file bot: force-sub, access tokens, universal links
- **Downloaders & media tools** — TeraBox downloader, video merger, and a clipper that cuts videos and uploads straight to Google Drive
- **Automation** — auto-approve for join requests, forwarders, group managers
- **Business software** — DhanLaxmi Finance, a loan manager (web + Android) for daily-EMI lending: customers, staff, collections, live tracking
